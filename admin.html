Bänder-Übersicht

Der gesamte Bestand: was im Lager liegt, was unterwegs ist und zu wem ein Band gehört. Bänder auf Lager lassen sich hier direkt einer offenen Bestellung zuteilen.

⚠️ Jedes Band bekommt seine eigene Adresse. Auf einen Chip gehört ausschliesslich eine Adresse aus der Spalte „URL für den Chip“ – also /n/ plus achtstelligem Code. Niemals dieselbe URL auf zwei Chips: beide zeigen sonst auf dasselbe Profil. Und ein persönlicher Verwaltungslink (/verwalten.html?t=…) darf nie auf ein Band, denn er gibt jeder Person, die das Armband scannt, vollen Zugriff auf die Daten inklusive Telefonnummer des Notfallkontakts.

⚠️ Basis-Adresse kontrollieren. Die Chips werden gesperrt – die aufgespielte Adresse lässt sich danach nicht mehr ändern. Aktuell würde – auf die Bänder geschrieben. Steht dort etwas anderes als die endgültige Domain, ist die ganze Charge Ausschuss. In diesem Fall zuerst BAND_URL_ORIGIN in js/config.js setzen.

CodeURL für den ChipAktion

Chip mit dem iPhone beschreiben – App „NFC Tools“

Pro Band einmal durchlaufen. Erst wenn Schritt 6 funktioniert hat, in Schritt 7 sperren – das lässt sich nicht rückgängig machen.

  1. Oben in der Tabelle beim gewünschten Code auf „URL kopieren“ tippen.
  2. NFC Tools öffnen, Reiter „Schreiben“, dann „Eine Aufzeichnung hinzufügen“.
  3. „URL / URI“ wählen, die kopierte Adresse ins Feld einfügen, mit „OK“ bestätigen.
  4. Unten auf „Schreiben“ tippen.
  5. Das Band an das obere Ende der iPhone-Rückseite halten, bis „Schreiben abgeschlossen“ erscheint.
  6. Kontrolle: App schliessen, das Band nochmals ans iPhone halten. Es muss oben ein Banner mit www.safeband.ch erscheinen; antippen – die Notfallseite öffnet sich. Erscheint kein Banner oder eine falsche Adresse: nicht sperren, Schritt 2 wiederholen.
  7. Zurück in NFC Tools, Reiter „Sonstige“ → „Tag sperren“, Band erneut anhalten. Damit kann niemand mehr die Adresse auf dem Band überschreiben.

Erst ins Lager legen, wenn der Chip gesperrt ist. Ein ungesperrtes Band kann jede fremde Person mit einem Handy auf eine beliebige Adresse umschreiben.

Mit NFC Tools gelesene oder aus Safari kopierte Adresse lässt sich direkt hier einfügen – der Code wird automatisch herausgelesen und filtert auf die passende Zeile.
